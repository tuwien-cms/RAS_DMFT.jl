Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

[Unreleased]

Added

  • quasiparticle_weight_inflections to calculate inflection of $Z(\lambda)$ (#222) (3c473bc)
  • quasiparticle_weight_optimum_regularization to find the regularization parameter λ at the first plateau of $Z(\lambda)$ on a logarithmic axis, with a prominence filter to discard shallow wiggles (#240) (05c4c0d)

Changed

  • AbstractPoles, AbstractPolesSum, and AbstractPolesContinuedFraction are now parameterized by (A, B) (#232) (ec0b81a)
  • amplitude constructor of PolesSumBlock accepts zero amplitudes, consistent with the weight-list constructor (#236) (8385d55)

Removed

  • discretize_similar_weight, discretize_to_grid (#225) (b010ad3)
  • submodule Debug from the public API (#228) (8c953db)

Fixed

  • correct eigenvectors and their adjoint in the self-energy from Schur complement (#235) (c2ea559)
  • clear ArgumentError from size on empty blocks of poles (#236) (105f69b)

[0.11.0] - 2026-08-14

Added

  • moments of complex function (#164) (da721d2)
  • transformation from sum of poles to Anderson form (#166) (1729012)
  • generalize self-energy to any 2n×2n block sum of poles (#167) (22f40e7)
  • get location of poles directly (#181) (78be1d5)
  • iterate through AbstractPolesSum (#182) (12f5719)
  • calculate filling for AbstractPolesSum (#183) (68c6489)
  • shift spectrum of AbstractPolesSum (#186) (d191feb)
  • calculate trace of AbstractPolesSum (#187) (5cf51be)
  • calculate thin rectangular amplitude (#195) (bfc7348)
  • local lattice Greens function in resolvent formalism (#201) (5b8c250)
  • enforce canonical representation for AbstractPolesSum (strictly increasing with no duplicates) (#203) (3ea3db4)
  • evaluate a pole representation at an arbitrary complex frequency z (#209) (273a6b0)

Changed

  • add regularization parameter for quasiparticle weight (#169) (8c3a40b)
  • PolesSum and PolesSumBlock are always sorted by increasing pole locations. Degenerate poles are automatically merged. (#175) (4f876e1)
  • explicitly specify matrix representation for given pole representation (#196) (80d9ae7) New methods are anderson_matrix, arrowhead_matrix, or tridiagonal_matrix.
  • Base.inv(::PolesSum) → inverse (#215) (7dbfc91)
  • natural_orbital_ci_operator → natural_orbital_ras_operator (#216) (d515549)

Removed

  • module ED (#198) (86ed14b)
  • finite broadening methods (#207) (f4b5a8d)
    • imagKK
    • realKK
    • greens_function_partial
    • quasiparticle_weight_gaussian
    • self_energy_IFG_gaussian
    • self_energy_IFG_lorentzian
    • δ_gaussian
  • equal_weight_discretization (#217) (0d6582e)

Fixed

  • lognormal broadening on a grid of type AbstractVector (#163) (2cb92dd)
  • allow zero length for AbstractPoles (#174) (7167664)
